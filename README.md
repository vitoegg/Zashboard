# Zashboard

基于 [Zephyruso/zashboard](https://github.com/Zephyruso/zashboard) 构建的精简面板：仅简体中文，无 PWA、地球可视化与自定义字体，更新检查指向本仓库。

```yaml
external-ui: ui
external-ui-url: https://github.com/vitoegg/Zashboard/releases/latest/download/dist.zip
```
